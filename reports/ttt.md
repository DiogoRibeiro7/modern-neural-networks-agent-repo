# Track 04 — Test-Time Training Layers

> Tables in this report are generated by `python scripts/report_ttt.py` from the records in
> `results/ttt/`. No number here is typed by hand.

## 1. Claim level

**`educational implementation`** — see [`docs/claim_policy.md`](../docs/claim_policy.md).

The primary source was retrieved and read in-environment, and the inner update, the inner
learning rate, and the batch-gradient-descent instantiation are checked against its
equations and Theorem 1. What is not claimed: any reproduction of the paper's results.
This implementation uses **pure online gradient descent** where the source uses mini-batch
TTT with `b = 16` and reports that change as its single largest quality gain, so these
numbers should be expected to fall short of the paper's configuration.

## 2. Sources

See [`docs/source_registry.md`](../docs/source_registry.md#track-04--test-time-training).

- Sun et al., *Learning to (Learn at Test Time): RNNs with Expressive Hidden States*,
  arXiv:2407.04620.

## 3. Method

Full formulation, the inner/outer loop table, shape table, equation-to-code mapping, and
the five deviations are in
[`src/modern_nn_lab/tracks/ttt/README.md`](../src/modern_nn_lab/tracks/ttt/README.md).

**What the headline metric measures.** On the rebinding task a key-value binding is
established, queried, then **overwritten**, then queried again. The reported metric is
accuracy on the *second* answer only — the one that requires revising something already
stored. The first answer is ordinary associative recall and is measured separately by the
selective-recall task.

**Fairness controls.** One shared training loop; baseline widths searched to match the TTT
parameter count; per-architecture learning-rate selection on validation; the test split
scored once; the frozen ablation differing from the default in exactly one flag, with an
identical parameter count; every seed recorded.

## 8. Failures and instabilities

**No run diverged.** All 79 records have `status="success"`.

**A record-collision bug was found and fixed before these numbers were produced.** The
first complete run reported three groups with only 2 seeds instead of 5. The cause: record
filenames keyed on `(architecture, variant, dataset, seed)`, and the context-scaling study
reused the dataset label `rebinding` for a *different* split (5 bindings instead of 3). The
scaled runs therefore overwrote three seeds of the main task, leaving groups that were both
incomplete **and** silently mixed results from two different datasets.

Three changes, all committed:

1. `ExperimentRecord.filename()` now includes the dataset *fingerprint*, so splits that
   share a label can never collide.
2. The scaled split is labelled `rebinding-5pairs`.
3. `scripts/validate_results.py` now fails when one aggregation group contains more than
   one dataset fingerprint — this class of bug is caught in CI from now on.

The lesson generalizes: **a dataset label is not a dataset identity.** Every earlier track
happened to escape this because its repeated tasks differed by variant name, not by
dataset parameters.

**Where the mechanism fails.** TTT loses to a matched-parameter LSTM on both tasks:
0.371 vs 0.493 on rebinding and 0.275 vs 0.296 on selective recall. It is not the best
model here on any measure except cost, where it is the worst.


## 9. Interpretation

**1. The inner loop is doing real work, and removing it is close to fatal.** The frozen
ablation is identical in every respect — same parameters, same views, same `W_0` — except
that the gradient step does not run:

| | rebinding (post-shift) | selective recall | chance |
|---|---|---|---|
| TTT-Linear | **0.371 ± 0.057** | **0.275 ± 0.062** | 0.167 / 0.125 |
| frozen learner | **0.221 ± 0.007** | **0.133 ± 0.021** | 0.167 / 0.125 |

Intervals are disjoint on both tasks. On selective recall the frozen variant sits *at
chance* (0.133 against 0.125), which is exactly what theory predicts: with `W_t = W_0` for
all `t` the layer stops being a sequence model at all and becomes a position-independent
function of each token — a fact asserted directly in
`test_frozen_learner_is_position_invariant`. It cannot carry information between positions,
so it cannot do recall. **This is the strongest form the required ablation can take: not a
weakened model, but the removal of the recurrence itself.**

**2. The distinction the track exists to make is enforced mechanically, not asserted.**
A forward pass runs gradient descent at every token and mutates **no** `nn.Parameter`
(`test_forward_pass_never_mutates_outer_parameters`), while the hidden state provably moves
at every step (`test_hidden_state_does_change_during_a_forward_pass`). Two further tests
pin down what that means in practice: the inner loop keeps running inside
`torch.no_grad()`, where evaluation happens, and outer gradients still reach `θ_K` and `θ_V`
— which enter the computation *only* through the inner loss — proving the outer loop
differentiates through the inner gradient step.

**3. Online gradient descent did not beat batch gradient descent here, which is the
opposite of what the source reports.** Batch GD scored 0.395 ± 0.022 against online's
0.371 ± 0.057 on rebinding, and the two tie on recall; the intervals overlap, so the honest
reading is *no detected difference*, not a reversal. Two things are worth separating. The
source's ablation compares batch GD against **mini-batch** GD with `b = 16` and finds the
latter much better; this implementation runs pure online GD (`b = 1`), an extreme the
paper's headline configuration does not use. At sequences of 16-24 tokens, `b = 1` means up
to 24 sequential steps of a noisy single-sample gradient, and the source's Figure 7 already
warns that very small `b` raises variance. **This is a limitation of the implementation
(deviation 1), not evidence against the source.**

**4. A more expressive inner learner did not help.** TTT-MLP scored 0.347 against
TTT-Linear's 0.371 on rebinding and 0.243 against 0.275 on recall — no gain, at ~1800 extra
parameters and the highest cost in the table. With a view width of 16 and 24 tokens to
learn from, the inner model's capacity is not the binding constraint; the number of
gradient steps available is.

**5. TTT closes the gap with the LSTM as the task gets harder, but the evidence is thin.**
At 3 bindings the LSTM leads 0.493 to 0.371. At 5 bindings — a longer sequence with more
interference — the ordering nominally reverses, 0.284 for TTT against 0.271 for the LSTM.
The intervals overlap heavily and there are only three seeds, so this is *a direction worth
testing properly*, not a result. It is reported because it is the one place where the
mechanism's premise — that in-sequence learning should pay off most when there is more to
revise — makes a prediction that could be checked at greater scale.

**6. The cost is severe and mostly incidental.** TTT-Linear's forward pass takes 37.6 ms
against the LSTM's 3.8 ms at a matched parameter count — roughly 10x. The frozen ablation,
which differs only by skipping the gradient, costs 7.2 ms, so **about 80 % of the cost is
the inner loop's backward pass and autograd graph construction**, not the layer's
arithmetic. That is precisely what the source's mini-batch formulation and dual form
eliminate, and neither is implemented here. No number in section 7 should be read as
evidence about what TTT costs when implemented properly.


## 10. Limitations

1. **Online GD only** (`b = 1`). The source's own ablation identifies mini-batch TTT as its
   largest single improvement, so this configuration is knowingly weaker than the paper's.
2. **No Mamba backbone and no temporal convolution**, which the source ablates separately.
3. **Short sequences** (T = 10 to 24) and a small view width (16), so the inner learner has
   little to store and little time to learn.
4. **One synthetic distribution shift.** The rebinding task changes the rule exactly once,
   at a fixed position. Nothing here speaks to gradual drift or repeated shifts.
5. **No language modelling**, so nothing bears on the source's reported results.

## 11. Next experiments

1. Implement mini-batch TTT and sweep `b` from 1 to `T`, reproducing the shape of the
   source's Figure 7 trade-off on these diagnostics.
2. Vary the shift position and the number of shifts, to separate "can revise once" from
   "can track a moving rule".
3. Sweep view width against the number of bindings, to find where the inner learner's
   capacity rather than its learning becomes the bottleneck.
4. Add TTT-MLP with the dual form so the richer inner model is affordable at longer context.
