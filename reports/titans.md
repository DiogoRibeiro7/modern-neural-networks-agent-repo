# Track 05 — Titans-Style Neural Long-Term Memory

> Tables in this report are generated by `python scripts/report_titans.py` from the records
> in `results/titans/`. No number here is typed by hand.

## 1. Claim level

**`educational implementation`** — see [`docs/claim_policy.md`](../docs/claim_policy.md).

The primary source was retrieved and read in-environment, and each term of the update rule
is checked against its equations. What is not claimed: any reproduction of the paper's
results, and any statement about **Memory as Context**, which is the variant the source
recommends and which this track deliberately does not implement.

One deviation is material enough to state up front: the update rule *as literally written*
diverges to `NaN` within five tokens at this scale, because the source specifies a
learnable `theta_t` with no numeric range. Bounding it, normalizing the keys, and averaging
the loss over features makes it stable. The dynamics reported here are therefore **a**
stable instantiation of the source's rule, not the authors' configuration.

## 3. Method

Full formulation, the variant-choice argument, shape table, equation-to-code mapping, and
the five deviations are in
[`src/modern_nn_lab/tracks/titans/README.md`](../src/modern_nn_lab/tracks/titans/README.md).

**The experiment is an interaction, not an accuracy.** A sliding window of size `W = 6`
should be sufficient when the queried fact lies within `W` tokens of the query and useless
beyond it. A working long-term memory should close that gap. So the manipulation is the
**write-to-query distance**, and the finding is how the architectures differ *across* it —
a single number at a single distance could not distinguish "has long-term memory" from
"has a long enough window".

**Fairness controls.** One shared training loop; baseline widths searched to match the
Titans parameter count; per-architecture learning-rate selection on validation; the test
split scored once; each ablation changing exactly one flag; every seed recorded.

## 8. Failures and instabilities

**No run diverged** in the reported experiments: all 60 records have `status="success"`.

**But the update rule diverged before the deviation was applied**, and that is the most
important instability in this track. With `theta_t = sigmoid(.)` unbounded relative to the
loss scale, the write loop is self-reinforcing — a larger memory gives a larger
reconstruction error, hence a larger gradient, hence a larger memory. Measured on random
input with the rule exactly as written:

| token | `max abs(M)` |
|---|---|
| 0 | 2.9 |
| 1 | 20.2 |
| 2 | 7.0e3 |
| 3 | 4.7e12 |
| 4 | 4.9e37 |
| 5 | `NaN` |

Bounding `theta_t` by 0.1, L2-normalizing keys and queries, and averaging the loss over
features holds `max abs(M)` at 0.12 after 40 steps and under 100 after 200 steps with
inputs scaled by 3. **This is deviation 1, and it was forced by measurement rather than
chosen.** A reader should treat the reported dynamics as one stable instantiation of the
source's rule, not as the authors' configuration.

**Where the mechanism fails.**

- At distance 2 — inside the short-term window — the full model (0.584 ± 0.011) is *worse*
  than both its frozen-memory ablation (0.643 ± 0.065) and its short-term-only ablation
  (0.629 ± 0.036). The gate does not learn to ignore a memory it does not need; an active
  but unhelpful memory branch actively costs accuracy.
- Repetition does not register as reduced surprise. Writing the same association twice
  leaves the mean associative loss essentially unchanged (114.3 versus 113.7, summed over
  the 64 diagnostic sequences, so roughly 1.8 each) and the mean surprise norm unchanged
  (0.390 versus 0.398). The source's surprise framing implies a repeated fact should be
  less surprising the second time; **that is not observed here.**
- The associative loss stays high in absolute terms (~1.8 per sequence), so the memory is
  fitting the key-value associations only partially even when it helps downstream.


## 9. Interpretation

**1. The memory helps exactly where the short-term window cannot reach, and the crossover
sits at the window size.** This is the track's central result, and it is an interaction
rather than a score. From the single-seed forgetting curve (window `W = 6`):

| write-to-query distance | with memory | short-term only | gap |
|---|---|---|---|
| 10 | 0.440 | 0.253 | **+0.187** |
| 8 | 0.320 | 0.133 | **+0.187** |
| 6 | 0.227 | 0.187 | +0.040 |
| 4 | 0.547 | 0.600 | -0.053 |
| 2 | 0.560 | 0.600 | -0.040 |

The gap is large and positive when the fact lies beyond the window, roughly zero at the
window boundary, and slightly negative inside it. The seeded comparison at the two
endpoints agrees: at distance 10 the full model scores 0.504 ± 0.070 against
short-term-only's 0.245 ± 0.012 (disjoint intervals), and at distance 2 the ordering
reverses within overlapping intervals. **A single accuracy number at a single distance
could not have distinguished "has a long-term memory" from "has a long enough window";
the curve can.**

**2. Momentum is not a refinement — without it the memory is worthless here.** Removing
past surprise (source eq. 14 reduced to eq. 8) collapses distance-10 accuracy to
0.237 ± 0.017, statistically indistinguishable from having no memory at all
(0.245 ± 0.012) and far below the full rule's 0.504 ± 0.070. The source motivates momentum
by arguing that the gradient goes flat after a surprising token, so a bare gradient rule
stops recording; at these sequence lengths that failure is total rather than marginal.

**3. Write rate is monotone in the way the mechanism predicts.** Ordering at distance 10:
full writes 0.504 > slow writes (`theta` x0.1) 0.333 > frozen 0.216. Both endpoints behave
as they should — a frozen memory is no better than no memory (0.216 vs 0.245, overlapping),
and slowing the write rate degrades but does not destroy the benefit.

**4. The Transformer baseline wins outright, and this must not be read as a defeat for the
mechanism.** Full causal attention scores 0.984 at distance 10 and 1.000 at distance 2. But
the baseline attends over the *entire* 12-token sequence, so "long distance" is nothing to
it; the comparison is between a windowed architecture and an unwindowed one, and at this
scale the unwindowed one simply has no problem to solve. **The informative comparison in
this track is Titans against its own ablations**, all of which share the same window. What
the Transformer result does establish is that the task is solvable, so the ablations'
failures are about memory rather than about task difficulty.

**5. An unhelpful memory is worse than no memory.** Inside the window the gated memory
branch costs 4-5 accuracy points relative to removing it. The gate in equation 28 is a
multiplicative combination with no mechanism that forces it toward the identity, and
nothing in the training signal rewards learning to ignore the memory when the attention
branch already suffices. This is a real limitation of MAG at this scale, and it is one
reason the source prefers Memory as Context.

**6. The write diagnostics show a memory that writes steadily but discriminates poorly.**
Mean forget gate 0.035 and mean learning rate 0.050 across tokens: the memory is retentive
and writes slowly and uniformly. It does *not* modulate its writes by content — the
repeated-fact trace is indistinguishable from the one-off trace. So the benefit measured in
point 1 comes from having *any* persistent associative store, not from the surprise signal
selecting what is worth storing. Distinguishing those two would need a task where most
tokens are worth ignoring, which is listed as a next experiment.

**7. Cost is dominated by the inner backward pass.** The full model's forward takes
42.4 ms against the frozen ablation's 11.0 ms at an identical parameter count, so roughly
**three quarters of the cost is writing**, not reading. Short-term-only costs 1.8 ms. The
source's Section 3.2 chunked formulation exists precisely to remove this, and is not
implemented here.


## 10. Limitations

1. **MAG only.** The source's recommended variant, Memory as Context, is not implemented,
   so nothing here bears on it.
2. **The stability deviation changes the dynamics.** Bounding `theta_t` to 0.1 caps how
   fast the memory can write; a different bound would give a different forgetting curve.
3. **Very short sequences** (T = 12) and a window of 6, so "long-term" here means ten
   tokens. Nothing scales to the context lengths the source studies.
4. **Two distances only** in the seeded comparison. The full forgetting curve is measured
   at single-seed resolution in the artefact, so its shape carries no uncertainty estimate.
5. **No language modelling**, and no comparison against the source's numbers.

## 11. Next experiments

1. Implement MAC and compare the three variants under this same diagnostic, which is the
   comparison the source's own ablation makes.
2. Put confidence intervals on the forgetting curve by running every distance across seeds,
   rather than only the two endpoints.
3. Sweep `theta_base` to map the stability boundary directly, turning deviation 1 from a
   fixed choice into a measured trade-off between write speed and divergence.
4. Push sequence length until the memory saturates, to measure capacity rather than only
   retention.
5. Test contradictory updates by combining this memory with the rebinding task from
   Track 04, where a fact is overwritten rather than merely distant.
