# Mathematical Notation

Use the following defaults unless a track has established source notation that would become less readable if changed.

- Batch size: `B`
- Sequence length: `T`
- Model width: `D`
- Hidden/state width: `H`
- Number of experts: `E`
- Input: `x`
- Target: `y`
- Hidden state: `h_t`
- Parameters: `theta`
- Learning rate: `eta`
- Loss: `L`

Every track README must contain a table mapping paper notation to code identifiers and tensor shapes.
